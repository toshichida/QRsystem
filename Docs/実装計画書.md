# 実装計画書

## 1. 文書の目的

本書は、QR コード受付システムを **完成させ GitHub Pages にデプロイするまで** の作業を、タスク単位のチェックリストとして整理する。[要件定義書](./要件定義書.md)、[リポジトリ構造定義書](./リポジトリ構造定義書.md)、[アーキテクチャ設計書](./アーキテクチャ設計書.md)、[API設計書](./API設計書.md) に沿って進める。

## 2. 開発前提（GAS・Clasp）

- **GAS のソース管理**: [google/clasp](https://github.com/google/clasp) を使い、リポジトリ内の `gas/`（[リポジトリ構造定義書](./リポジトリ構造定義書.md)）を **ローカルの編集対象**とする。
- **エディタ**: **Cursor** 上で `gas/` 以下の `.gs` 等を編集する。
- **デプロイ先**: スプレッドシートに紐づく **コンテナバインドスクリプト**（Spreadsheet-bound project）を正とし、作業後は **`clasp push`** で Google 側のそのスクリプトへ反映する。
- **初回**: `clasp login` で認証し、対象コンテナバインドプロジェクトの **scriptId** を `.clasp.json` に設定する（既存を `clasp clone <scriptId> --rootDir gas` 等で取り込んでもよい）。
- **日々の流れ**: コード変更 → `clasp push` →（必要なら GAS エディタまたは `clasp open` で動作確認）→ ウェブアプリの再デプロイが必要な変更では **デプロイをやり直す**。

## 3. 使い方

- 完了したタスクは `- [ ]` を `- [x]` に変更する。
- 順序は推奨。並行可能な箇所はフェーズ内で調整してよい。
